QUICK START (3 Steps)
---------------------

1. Copy the rsn_libsurvive folder to your solution directory

2. In your Visual Studio project:
   Right-click Project → Add → Existing Property Sheet
   → Browse to rsn_libsurvive\libsurvive.props → Open

3. Include the header and start coding:
   #include <libsurvive/survive_api.h>

   See example_usage.cpp for complete working example.


WHAT'S INCLUDED
---------------

✓ DLLs & Executables (6 files)
  - libsurvive.dll (main library)
  - survive-cli.exe, api_example.exe, sensors-readout.exe, etc.

✓ Plugins (10 DLLs)
  - Drivers: driver_vive.dll, driver_playback.dll, etc.
  - Posers: poser_mpfit.dll, poser_barycentric_svd.dll, etc.

✓ Import Libraries (4 .lib files)
  - libsurvive.lib
  - cnkalman.lib, cnmatrix.lib, mpfit.lib

✓ Headers (~399 files)
  - libsurvive API headers
  - cnkalman, cnmatrix libraries
  - Eigen 3.4 math library
  - mpfit optimization library


MANUAL INTEGRATION (If not using .props)
-----------------------------------------

Project Properties → Configuration Properties

C/C++ → General → Additional Include Directories:
  $(SolutionDir)rsn_libsurvive\include

Linker → General → Additional Library Directories:
  $(SolutionDir)rsn_libsurvive\lib

Linker → Input → Additional Dependencies:
  libsurvive.lib
  cnkalman.lib
  cnmatrix.lib
  mpfit.lib

Build Events → Post-Build Event → Command Line:
  xcopy /Y /D "$(SolutionDir)rsn_libsurvive\bin\*.dll" "$(OutDir)"
  xcopy /Y /D /E "$(SolutionDir)rsn_libsurvive\bin\plugins" "$(OutDir)plugins\"

TESTING THE INSTALLATION
-------------------------

1. Test survive-cli.exe:
   > cd rsn_libsurvive\bin
   > survive-cli.exe --help

2. Test api_example.exe:
   > cd rsn_libsurvive\bin
   > api_example.exe
   (Should initialize and wait for devices)

3. Build and run example_usage.cpp in your project


COMMON ISSUES
-------------

Issue: "Cannot open include file: 'libsurvive/survive_api.h'"
Fix: Check that include path is set correctly
     Path should be: rsn_libsurvive\include

Issue: "Unresolved external symbol"
Fix: Make sure you're linking all 4 .lib files
     Check that library directory path is correct

Issue: "libsurvive.dll not found"
Fix: Post-build event didn't run or failed
     Manually copy libsurvive.dll to your Debug/Release folder
     Make sure plugins\ folder is also copied

Issue: "No devices detected"
Fix: - Close SteamVR (it conflicts with libsurvive)
     - Check USB connections
     - Run as Administrator if needed

USING THE SIMPLE API
---------------------

Basic pattern:

  #include <libsurvive/survive_api.h>

  int main(int argc, char** argv) {
      // Initialize
      SurviveSimpleContext* ctx = survive_simple_init(argc, argv);

      // Main loop
      while (survive_simple_wait_for_update(ctx)) {
          for (auto obj = survive_simple_get_next_updated(ctx);
               obj != NULL;
               obj = survive_simple_get_next_updated(ctx)) {

              SurvivePose pose;
              survive_simple_object_get_latest_pose(obj, &pose);

              // Use pose.Pos[0,1,2] for position
              // Use pose.Rot[0,1,2,3] for rotation (quaternion)
          }
      }

      // Cleanup
      survive_simple_close(ctx);
      return 0;
  }

See example_usage.cpp for complete working code.


COMMAND LINE OPTIONS
--------------------

Pass to survive_simple_init(argc, argv):

  --v 100                Verbose output
  --v 150                Very verbose (per-pose output)
  --force-calibrate      Recalibrate lighthouses
  --lighthouse-gen 2     Force lighthouse generation (1 or 2)
  --playback file.rec    Playback recorded session
  --record file.rec      Record session for later playback
